BAR-Governed HDAE Implementation Toolkit

This toolkit operationalizes the BAR-HDAE dual-loop model. The outer BAR lifecycle governs whether, where, and to what extent an AI-enabled capability should be adopted and scaled. The inner HDAE loop governs how one authorized human outcome episode is planned, mediated, executed, verified, and recovered.

Original site Open the live demo View source on GitHub Read the README Reference architecture

Scope. The underlying manuscript is conceptual and has not been empirically validated. This toolkit is a design-science-oriented implementation artifact for demonstrating the method. It is not evidence that the theory or its measures are validated, and it does not connect to live enterprise systems.

What it includes

  • Four BAR evidence gates (G0 business legitimacy, G1 architecture readiness, G2 controlled pilot, G3 enterprise scale), treated as minimum evidence rather than weighted scores.
  • Seven HDAE phases from scoping an outcome episode to validating, learning, and scaling.
  • Twelve artifacts, including the Outcome Charter, Intent Envelope Schema, Agent Authority Profile, Policy and Control Pack, and Transaction and Recovery Map.
  • A governed runtime with fail-closed mediation, a hash-chained trace, and recovery handling.
  • A guided wizard, sample scenarios, metrics catalog, and L0-L4 maturity model.

Run the interactive demo

A hosted demo runs on Cloudflare at hdae-implementation-toolkit.bhagyesh-chokhawala.workers.dev (demo sign-in is shown on the login page). The first load after idle can take a few seconds. To run it yourself with Docker:

git clone https://github.com/Bhagyesh-Chokhawala/HDAE_Implementation_Toolkit.git
cd HDAE_Implementation_Toolkit
docker build -t hdae-toolkit .
docker run --rm -p 8000:8000 -e SECRET_KEY="change-me" hdae-toolkit

Open http://127.0.0.1:8000. The demo sign-in is for local demonstration only (user admin, password hdae-admin). Without Docker, create a virtual environment, run pip install -r requirements.txt, and start PORT=8000 python wsgi.py.
