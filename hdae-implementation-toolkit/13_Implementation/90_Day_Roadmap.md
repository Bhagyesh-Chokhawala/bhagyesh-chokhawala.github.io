# 90-Day HDAE Roadmap

## Days 1–15
Select one bounded outcome; assign owners; complete intent canvas; map capability; classify autonomy/risk.

## Days 16–30
Create Intent Envelope, Authority Profile, Outcome Contract, Policy Pack, and Recovery Map.

## Days 31–45
Register agent; integrate tools/APIs; place policy/authority checks before state changes; add idempotency and approval checkpoint.

## Days 46–60
Implement evidence, observability, pause/cancel/override, compensation, and recovery.

## Days 61–75
Test happy path, expired intent, unauthorized action, missing approval, policy outage, timeout, duplicate request, partial failure, invalid tool/action, and emergency stop.

## Days 76–90
Controlled pilot; limit blast radius; compare to baseline; review traces; measure outcome, policy, recovery, intervention, and cost metrics; approve or reject autonomy expansion.
