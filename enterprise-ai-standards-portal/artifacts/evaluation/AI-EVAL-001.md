# AI-EVAL-001 — Regression and Risk Evaluation

**Domain:** Evaluation  
**Requirement:** MUST  
**Applicable risk tiers:** R1, R2, R3, R4  
**Lifecycle phases:** Build & Evaluation, Deployment

## Standard

Material changes to model, prompt, retrieval, embeddings, agent workflow, tool set, or safety policy must trigger applicable regression and risk evaluation.

## Required controls

- Evaluate task quality and groundedness
- Evaluate hallucination and safety
- Evaluate prompt-injection resistance
- Evaluate tool correctness
- Evaluate latency and cost
- Evaluate bias when applicable

## Required evidence

- Evaluation report
- Baseline comparison
- Security evaluation
- Performance/cost results

## Framework mapping

- Technology Readiness
- Security
- Ethics
- Governance
