# AI-PROMPT-001 — Prompt Versioning and Secure Prompt Management

**Domain:** AI Engineering  
**Requirement:** MUST  
**Applicable risk tiers:** R1, R2, R3, R4  
**Lifecycle phases:** Implementation, Build & Evaluation

## Standard

Production prompts are version-controlled engineering assets with owners, model compatibility, schemas, risk classification, and evaluation suites.

## Required controls

- Version prompts in source control
- Declare owner, purpose and compatible models
- Prohibit secrets and credentials in prompts
- Bind prompt changes to regression evaluation
- Record deployed prompt version

## Required evidence

- Prompt manifest
- Source-control history
- Secret scan
- Prompt regression results

## Framework mapping

- Developer Enablement
- Security
- Governance
