# AI-MODEL-001 — Governed Model Access

**Domain:** AI Engineering  
**Requirement:** SHOULD  
**Applicable risk tiers:** R1, R2, R3, R4  
**Lifecycle phases:** Architecture, Implementation, Runtime

## Standard

Use an enterprise model gateway or equivalent control point for model allow-listing, provider routing, data policy, logging, cost controls, and versioning.

## Required controls

- Use approved model/provider list
- Enforce data retention and region policies
- Apply token, rate and cost limits
- Log model/version and route decisions
- Define provider/model failover

## Required evidence

- Model registry
- Gateway configuration
- Provider assessment
- Cost/rate policy

## Framework mapping

- Technology Readiness
- Developer Enablement
- Security
