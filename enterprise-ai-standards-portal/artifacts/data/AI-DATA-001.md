# AI-DATA-001 — Trusted Data and Knowledge Sources

**Domain:** Data & Knowledge  
**Requirement:** MUST  
**Applicable risk tiers:** R1, R2, R3, R4  
**Lifecycle phases:** Architecture, Implementation

## Standard

Production AI must identify authoritative data and knowledge sources with ownership, classification, lineage, retention, quality, and permitted AI usage.

## Required controls

- Assign data owner/steward
- Classify sensitivity
- Document lineage and freshness
- Define retention and permitted AI use
- Validate data quality expectations

## Required evidence

- Data inventory
- Classification record
- Lineage view
- Data quality report

## Framework mapping

- Technology Readiness
- Security
- Governance
