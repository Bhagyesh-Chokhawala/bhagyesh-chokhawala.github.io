# AI-SEC-001 — Attributable Identity for AI Actions

**Domain:** Security  
**Requirement:** MUST  
**Applicable risk tiers:** R2, R3, R4  
**Lifecycle phases:** Architecture, Implementation, Runtime

## Standard

Protected AI interactions and tool actions must be attributable to user, application, agent, and tool identities where applicable.

## Required controls

- Authenticate protected interactions
- Propagate user and service identity
- Use distinct agent/tool identity when practical
- Avoid shared generic administrative credentials

## Required evidence

- IAM design
- Identity propagation test
- Authentication logs

## Framework mapping

- Security
- Governance
