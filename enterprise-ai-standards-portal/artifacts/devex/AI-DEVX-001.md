# AI-DEVX-001 — Governed Developer Enablement

**Domain:** Developer Experience  
**Requirement:** SHOULD  
**Applicable risk tiers:** R1, R2, R3, R4  
**Lifecycle phases:** Implementation, Build & Evaluation

## Standard

The governed path should be the easiest delivery path through reusable SDKs, templates, evaluation harnesses, observability libraries, and CI/CD controls.

## Required controls

- Provide approved model/RAG/agent templates
- Provide policy and observability libraries
- Provide evaluation test harnesses
- Document reference architectures
- Maintain self-service onboarding

## Required evidence

- SDK/template repository
- Reference implementation
- Developer onboarding guide
- Adoption metrics

## Framework mapping

- Developer Enablement
- Governance
