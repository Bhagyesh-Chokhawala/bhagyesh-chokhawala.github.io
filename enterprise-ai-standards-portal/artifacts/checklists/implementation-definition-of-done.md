# Implementation Definition of Done

- [ ] Business capability is identified
- [ ] Architecture is approved
- [ ] System of record and transaction boundaries are documented
- [ ] Model access uses the approved path
- [ ] Data classification and permitted AI use are complete
- [ ] RAG sources are authorized and provenance is preserved
- [ ] Prompt is version controlled and contains no secrets
- [ ] Agent permissions and resource budgets are explicit
- [ ] State-changing actions use controlled domain APIs
- [ ] Transaction safety and compensation are validated
- [ ] Security tests pass
- [ ] Ethical impact assessment is complete when applicable
- [ ] Evaluation suite passes
- [ ] Observability is implemented
- [ ] Human escalation path exists
- [ ] Cost and rate limits are established
