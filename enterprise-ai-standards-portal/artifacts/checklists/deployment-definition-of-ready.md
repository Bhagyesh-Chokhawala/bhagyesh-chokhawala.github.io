# Deployment Definition of Ready

- [ ] Risk tier assigned and approved
- [ ] Release evidence package is complete
- [ ] Security controls and tests are complete
- [ ] Responsible AI / ethics requirements are complete
- [ ] Model, prompt, policy, retrieval/index, and tool versions are pinned
- [ ] Evaluation baseline is recorded
- [ ] Performance and cost tests passed
- [ ] SLOs and alert thresholds are defined
- [ ] Runbook is available
- [ ] Rollback is tested
- [ ] Kill switch is verified where required
- [ ] Support and incident owners are identified
- [ ] Business owner accepts release
- [ ] Production monitoring owner is assigned
- [ ] No mandatory control is Red
