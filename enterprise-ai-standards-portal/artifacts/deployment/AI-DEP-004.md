# AI-DEP-004 — Progressive AI Rollout

**Domain:** Deployment  
**Requirement:** SHOULD  
**Applicable risk tiers:** R3, R4  
**Lifecycle phases:** Deployment, Runtime

## Standard

High-impact AI solutions should progress through offline evaluation, shadow mode, controlled cohorts, and staged production exposure with stop thresholds.

## Required controls

- Define rollout stages and cohorts
- Set automatic/manual stop thresholds
- Monitor quality, safety, latency, cost and incidents
- Require explicit promotion decisions

## Required evidence

- Rollout plan
- Canary metrics
- Promotion decisions
- Stop-threshold configuration

## Framework mapping

- Technology Readiness
- Security
- User Trust & Completeness
