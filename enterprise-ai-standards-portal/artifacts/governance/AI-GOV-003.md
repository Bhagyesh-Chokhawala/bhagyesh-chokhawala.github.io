# AI-GOV-003 — Production Release Evidence Bundle

**Domain:** Governance  
**Requirement:** MUST  
**Applicable risk tiers:** R2, R3, R4  
**Lifecycle phases:** Deployment, Runtime

## Standard

Each production release must retain traceable evidence linking architecture, model/provider, security, ethics, evaluation, operations, and approval decisions.

## Required controls

- Create release evidence directory or equivalent system record
- Link evidence to immutable release ID
- Protect evidence from unauthorized modification
- Retain according to policy
- Make evidence queryable for audit and incident review

## Required evidence

- Release evidence manifest
- Architecture evidence
- Security and ethics evidence
- Evaluation report
- Runbook and rollback plan
- Approval decision
