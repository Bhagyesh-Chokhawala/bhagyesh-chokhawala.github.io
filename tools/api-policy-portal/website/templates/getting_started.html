Developer onboarding

Getting started

Install the central validator, inspect the policy catalog, validate an API repository, and publish the result to the portal.

1

Install

python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
2

Inspect policies

api-standards catalog
3

Validate a target API

api-standards validate /path/to/my-api \
  --json-report validation-results/my-run/policy-report.json \
  --markdown-report validation-results/my-run/policy-report.md
4

Build the portal

api-standards portal build \
  --results validation-results \
  --output public

Open public/index.html or run api-standards portal serve --directory public.
