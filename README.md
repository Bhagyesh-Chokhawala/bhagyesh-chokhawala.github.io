# GitHub Pages starter

## Before publishing

1. Replace every occurrence of `bhagyesh-chokhawala` with your actual lowercase GitHub username.
2. Replace the abstract placeholder in:
   `publications/capability-centric-enterprise-architecture/index.html`
3. Put the searchable PDF in:
   `publications/capability-centric-enterprise-architecture/capability-centric-enterprise-architecture.pdf`
4. Confirm the PDF is under 5 MB, text-searchable, has the title prominently at the top of page 1, the author directly below it, and a References/Bibliography section.
5. Update `citation_publication_date` if the correct citation year differs.

## Publish with GitHub Pages

Create a public repository named:

`bhagyesh-chokhawala.github.io`

Upload all files and folders from this package to the root of that repository.

Then open:

Settings → Pages → Build and deployment → Source → Deploy from a branch

Choose:

- Branch: `main`
- Folder: `/ (root)`

Save, then use **Visit site** after deployment finishes.

## Test after publishing

Open these URLs in a private/incognito browser:

- `https://bhagyesh-chokhawala.github.io/`
- `https://bhagyesh-chokhawala.github.io/publications.html`
